## Project Motivation

Credit card default can cause financial losses for banks. Predicting which clients are likely to default can help financial institutions assess credit risk, make informed lending decisions, and reduce potential losses.

In this project, we use machine learning to predict whether a client will default on their credit card payment next month.

## Dataset

We use the Default of Credit Card Clients dataset from Kaggle. It contains information about 30,000 clients in Taiwan, including credit limits, demographic information, repayment status, bill amounts, and previous payments.

Dataset source: https://www.kaggle.com/datasets/uciml/default-of-credit-card-clients-dataset

## Project Goal

The goal of this project is to explore and preprocess the dataset, train machine learning models, and evaluate their performance in predicting credit card default. The project aims to investigate how effectively machine learning can support credit risk assessment.
