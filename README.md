# SWE485-Project-Group1
# Credit Card Default Prediction

## Group Members

## Project Motivation

Credit card default can cause financial losses for banks. Predicting which clients may default can help banks assess credit risk and make better decisions.

In this project, we use machine learning to predict whether a client will default on their credit card payment next month.

## Dataset

We use the Default of Credit Card Clients dataset from Kaggle. It contains information about 30,000 clients in Taiwan, including their credit limits, repayment status, bill amounts, and previous payments.

Dataset source: https://www.kaggle.com/datasets/uciml/default-of-credit-card-clients-dataset

## Project Goal

The goal is to explore and prepare the dataset, train machine learning models, and evaluate their performance in predicting credit card default.
