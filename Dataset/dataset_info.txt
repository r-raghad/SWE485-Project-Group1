Number of Rows: 30,000

Number of Columns: 25

Target Column: default.payment.next.month

Problem Type: Binary Classification

Target Classes:

* 0 = No default
* 1 = Default

Missing Values: 0

Duplicate Rows: 0

Description:
This dataset contains information about 30,000 credit card clients in Taiwan. It includes demographic information, credit limits, repayment status, bill amounts, and previous payments. It can be used to predict whether a client will default on their credit card payment next month.

Original Purpose:
Collected for a research study (Yeh & Lien, 2009) comparing data mining methods for predicting the probability of default among credit card clients in Taiwan.
